# behavior-transform.io Product

behavior-transform.io is the Project Telos private-line IO boundary calibration
layer. It gives local tools a consistent way to route reads, writes, exec,
fetch, input, and model-boundary events through mode-aware receipts.

## Users

- Operators running local AI workflows across CLIs and model hosts.
- Maintainers instrumenting hooks, wrappers, and shell profiles.
- Host integrations that need hashes, counts, verdicts, and redacted references.

## Product Promise

behavior-transform.io makes boundary crossing explicit without forcing raw
private payloads into public logs, model context, or release artifacts.

## Evidence

The product emits doctor/demo receipts, hook checks, profile state, channel
identity, mode verdicts, hashes, counts, and redacted references.
