# Support

Use GitHub issues for public behavior-transform support:

- IO wrapper, receipt, or redaction regressions
- integration problems in local read, write, exec, fetch, or input channels
- documentation gaps in boundary behavior
- reproducible compatibility issues

Use `SECURITY.md` for vulnerabilities or sensitive reports.

Do not post credentials, private session material, raw exploit details, bypass
payloads, auth headers, cookies, raw private corpora, or client data. Include
the behavior-transform commit, command, sanitized receipt verdict, channel type,
and the smallest reproduction that preserves the privacy boundary.
