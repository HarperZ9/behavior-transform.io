# behavior-transform.io Supply Chain

## Dependency Manifest

behavior-transform.io uses this file and `pyproject.toml` as its public
dependency and provenance manifest.

## Provenance

Release receipts are generated from local repository state and public GitHub CI
metadata. Raw file contents are not exported in release receipts.

## Maintenance

GitHub Actions dependencies are maintained through `.github/dependabot.yml`.

## Secret Boundary

Secrets, credentials, private sessions, raw exploit material, and live access
data are not part of the public supply-chain record.
